# PRIVACY.md — ZentraDL

No ads, analytics or telemetry. Network calls only when the user triggers them
(downloads/trackers) plus optional user-enabled checks (tracker-list, IP-filter,
update check — all off by default). All smart features on-device; no cloud/AI.
Logs stay local; "share logs" redacts URLs and tokens. Credentials in
Keystore-encrypted vault (opt-in, wipeable). First-run "use responsibly" notice;
no built-in torrent search/indexers; no DRM circumvention.
